# QiBit 3D 人物 Agent 家族

以七张既有透明 PNG 为视觉基准，复用现有人物或设计能自然加入同一家族的新 Agent。用户当前明确要求优先；本模板锁定家族语言，不锁定每次的人数、岗位、性别或排版。

## 先读取参考

- 读 `artifact-template.json`，相对本技能目录解析 `assets/reference.png` 与 `assets/preview.png`，先看家族总览。
- 七张未经改动的原始头像位于 `assets/characters/`。需要编辑或复现现有人物时，读 [references/characters.md](references/characters.md)，查看对应原图；角色身份以原图为准，文字卡只作定位。
- 总览是由七张原图排版生成的参考索引；其中的七人数量、两行布局、浅色底和岗位标签不构成新图要求。原始头像均为 1024×1024 RGBA PNG。
- 不修改、替换或移动技能内的参考资产；新作品保存到当前任务的用户输出目录。本技能独立保留全部原图，后续不依赖原聊天、桌面路径或临时剪贴板。

## 家族共同语言

**造型与比例**：精致、风格化的 3D 成年人物。头部略大，眼睛相对面部偏大，颈肩自然；面部骨骼与鼻唇结构经过柔化概括，保留成人身份。基准是当前参考中的年轻、亲和感，不自动改为写实证件照，也不进一步缩成婴幼儿、Q版小人或头身等大的玩偶。半身参考不定义全身头身比。

**五官与表情**：棕色虹膜、清晰瞳孔、白眼球与柔和高光；眉形清楚，鼻梁圆润，嘴唇薄而自然。默认平视、轻微闭嘴微笑，表达专注、温和与可靠。眼神有生命感，避免空洞玻璃眼、强烈媚态、夸张表情或无意把所有人变成同一张脸。不要把星星 IP 的纯黑双眼规则套到人物上。

**皮肤**：细腻平滑的哑光数字雕塑表面，带轻微透光感和面颊、鼻尖的柔和暖色；明暗过渡宽而柔和。保留轻微面部体积，不增加明显毛孔、皱纹或摄影级皮肤细节；避免蜡亮、湿亮、橡胶与油腻塑料反光。年龄与肤色可按用户需求扩展，不把现有样例的外貌范围当成家族限制。

**头发**：先建立清晰的发型轮廓，再用有方向的大束发块和细发丝塑造层次。发量饱满，边缘干净，带克制的缎面反射；不默认制作每根飞散的写实发丝，也不把头发简化成一整块光滑头盔。

**衣料与配色**：毛衣、牛仔、棉衬衫与西装面料有可读的织纹、领口、缝线和适度褶皱，细节比皮肤更丰富。服装是简洁的日常职场休闲款。当前家族以黑、深蓝、灰绿、灰粉、米白、灰蓝和棕色为主；新增角色可引入协调的新色，不强制每个岗位对应某种颜色或西装。单个角色通常一个主衣色加一个中性内搭。

**光照与构图**：正面至轻微三分之四视角，柔和棚拍主光与补光，低对比阴影，面部亮度均匀。默认单人居中胸像，完整保留头顶和发梢，两肩自然展开，底部裁于胸部；头像组保持相近脸部尺度和镜头距离。透明背景用于可复用头像；背景有明确要求时按用户要求。默认不添加文字、Logo、场景或职业道具。

风格锚点是“温和、精致、具有成人职场身份的 3D 卡通人物”。不要引入另一套早期成熟半写实七人图、圆角星星、Dark 发光材质或网站玻璃界面作为角色风格。

## 按请求选择模式

### 复用现有角色

仅需要原头像文件时直接交付对应原图副本，保留透明通道，不重新生成。需要新姿态、表情、服装或场景时，先看该角色原图，把它作为身份来源；家族总览只提供统一风格。只改变用户指定的属性，锁定其余脸型、发型、发色、眼镜、胡须与服装等特征。完整身份表见 [characters.md](references/characters.md)。

### 新增同风格 Agent

家族总览是风格来源，新角色 brief 是身份来源。数量和岗位来自当前请求；“新增一个”就生成一位，不补齐七位。未指定的非关键细节可给出协调的方案，不因年龄、性别或衣色缺省而反复询问。

先给每个新角色一个简短参数卡：岗位／名称、脸部轮廓、发型轮廓、表情、服装及主色、可选眼镜或胡须、构图。至少在脸型、发型、配饰、服装轮廓中的两项与现有人物形成可见差别；配色辅助辨识，不能只复制同一张脸换衣色。这个“至少两项”是减少撞脸的设计方法，不要求用户先补齐参数。

保留共同眼睛语言、材质、灯光和精致度。岗位不决定性别、肤色或年龄，也不必通过法槌、计算器、耳机等道具表达。用户主动要求道具或不同人口特征时自然纳入统一风格。只为请求的新角色生成，不同时改动原七位。

### 多角色家族与独立素材

合影／家族方案图可在一张图中生成指定人数，按 brief 排列。需要 N 张独立透明素材时，使用图像工具分别生成并保存 N 个文件；家族图不能代替独立头像。为统一风格，固定共同提示词与光照描述，逐个修改身份参数。

## 生成与检查

生成或编辑时使用 `$imagegen` 技能与内置图像工具；只询问设计方案或提示词时直接回答，不自动生图。读 [references/prompt-kit.md](references/prompt-kit.md)，按当前模式选用提示词并填完参数。

先用图像查看工具检查将要提供的本地参考。给图像工具传入参考路径，并明确每张图的作用；推荐家族总览加目标角色原图，避免把七张原图全部塞入一次输入。编辑现有角色时，目标原图锁定身份，总览只锁定风格；新增角色时，总览只锁定风格，不复制其中某人的身份。

透明头像使用图像工具的真实透明背景选项。保持原生 alpha，不把白底或棋盘格画进图片，不用重新抠图冒充生成器已输出透明。若需精确尺寸，先按可用工具能力生成，检查实际尺寸；不能只在提示词写 1024×1024 就宣称已满足。

检查：人数和岗位是否正确；是否保留成年身份与参考中的风格化程度；大眼睛、柔和脸部、发束和织物细节是否一致；人物是否撞脸；编辑中未授权特征是否变化；头顶是否完整；眼镜与头发边缘是否清楚。透明图检查 alpha 通道，并在浅底和深底上观察边缘。修改问题时一次集中修正一个主要偏差。

图像生成无法保证身份逐像素一致；如用户要求原样使用，回到原始 PNG 副本。生成结果用新文件名保留旧版，最终提供可查看的图片与保存位置。

调用示例：
- “按这七个人的风格新增一个法务 Agent，透明底半身像。”
- “只把现有技术 Agent 的表情改成专注，保留脸、发型和牛仔外套。”
- “新增三位研究、客服、招聘 Agent，分别输出独立透明 PNG，脸型和发型要有差别。”
