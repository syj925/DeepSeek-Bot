# 可复用提示词

先看总览与本次需要的原图，再写提示词。以下共同风格可复用；方括号参数应在调用前替换。岗位的外貌设计是创作选择，不是事实或永久规范。

## 共用风格块

```text
精致的风格化3D成年人物，沿用附图中QiBit人物家族的建模与渲染语言。
头部略大、棕色眼睛相对面部偏大，清晰虹膜与柔和眼部高光；
保留成年人的颈肩与鼻唇结构，脸部转折圆润、概括，亲和而有职场身份。
皮肤细腻平滑、偏哑光，带轻微柔和透光和自然暖色，不添加写实毛孔。
头发用清晰的大束发块建立轮廓，细发丝顺着发束走势，反射柔和。
衣料有克制的织纹、缝线、领口和褶皱，材质区分清楚。
柔和棚拍主光与补光，低对比阴影，面部明亮，镜头接近平视。
平静、友善、轻微闭嘴微笑，默认单人居中胸像，完整头顶与发梢可见。
不增加文字、Logo、水印、场景、职业工具或其他人物。
避免摄影级真人、婴幼儿比例、夸张Q版、2D平涂、过亮塑料皮肤、
头盔般头发、霓虹轮廓、强烈戏剧光、大笑露齿，以及复制同一张脸换衣服。
```

## 新增一个 Agent

图像输入：家族总览 `assets/reference.png`。新角色只借鉴风格，不继承任一既有人物的身份。

```text
Use case: stylized-concept
Asset type: reusable 3D human Agent portrait
Primary request: 为QiBit家族新增一位[岗位／名称] Agent。
Input image 1: 仅提供人物比例、五官风格、皮肤、头发、衣料和光照的家族参考；
不要照抄七人数量、参考排版、标签文字、背景或其中任何人的脸。
新身份：[脸型]；[发型与发色]；[可选眼镜或胡须，无则明确无]；
[服装轮廓]，主色[衣色]、内搭[颜色]；[表情与姿态]。
[插入共用风格块]
Output: 恰好一位，居中胸像，无字，真实透明背景；
脸部与发型相较原七位有清楚差别，保持相同精致度和柔和灯光。
```

在工具参数中实际设置透明背景。用户指定年龄、性别、肤色、配饰等时直接使用；未指定时选择协调方案，不把上述参数卡变成必答问卷。

## 现有角色的局部编辑

图像输入 1：要改的单张角色原图；图像输入 2：家族总览。顺序以实际传入工具的顺序为准。

```text
Use case: precise-object-edit
Asset type: existing Agent portrait revision
Primary request: 只修改[角色]的[表情／服装／姿态／其他明确属性]为[目标]。
Input image 1: 编辑目标与身份来源。
Input image 2: 家族风格参考，不用于替换目标人物。
只改变上述属性。保留目标人物的脸型、五官身份与基础结构、发型、发色、眼镜、胡须、
衣料、配色、构图与原生透明度中所有未被授权改变的部分。
延续原图3D风格化程度、柔和棚拍光和材质细节。
恰好一位，无新增道具、文字或人物。
```

删去保持清单中本次明确允许修改的属性，避免同一提示词同时要求改与不改。表情编辑允许为指定表情微调眉、眼睑和嘴角，保留五官身份，不冻结动态表情。用户要求换姿态时，原图提供身份，不必锁死原来的头部角度。

## 独立多角色素材

先写各人的参数卡，保持共用风格块一致；每位分别调用图像工具。每次只传本次角色的身份来源与共用风格参考，不沿用上一位新生成角色的脸作为所有人的底模。

例：用户要研究、客服、招聘三位时，可以提出以下协调方向；这些是可替换设计选择，不构成新角色的固定设定。

| 示例岗位 | 脸型与发型的区别 | 服装方向 |
|---|---|---|
| 研究 | 较长椭圆脸、齐整深色短卷发 | 烟灰开襟针织＋米白内搭 |
| 客服 | 柔和方圆脸、深棕齐肩直发 | 柔和蓝绿衬衫 |
| 招聘 | 较宽脸型、短侧分发 | 深酒红轻便外套＋浅灰内搭 |

不自动根据岗位固定性别或肤色；无需给客服增加耳机。保存三个独立文件并检查是否撞脸，不把三人拼图作为独立素材交付。

## 家族方案图

```text
沿用附图人物家族的统一建模、面部比例、材质和柔和棚拍光。
生成恰好[数量]位[用户要求的角色列表]，人物身份和排列为[本次布局]。
每位采用不同的脸型与发型，[按需补充人物卡]。
统一镜头距离、脸部尺度、衣料精度和明暗对比，头顶完整，人物之间不遮挡。
背景为[用户要求；无要求可使用干净浅色]。
[只有明确要求文字时，列出逐字标签；否则写无字。]
总览参考只控制家族风格，不要求生成原有七位或沿用两行排版。
```

## 常见偏差的定向修正

- 太像真人：加强圆润概括的脸部建模和眼睛的风格化比例，减少毛孔与摄影细节；不降低织物质感。
- 太像幼儿：恢复成年颈肩、鼻唇与下颌结构；维持参考的大眼风格，不改成写实小眼。
- 新角色撞脸：优先改脸型与发型轮廓，再调衣领和配色；不要只增添眼镜。
- 编辑丢失身份：重新提供角色原图为目标，仅缩小本次修改范围；不要继续拿已漂移的人物作唯一来源。
- 透明边缘异常：先确认实际alpha和深浅底表现；需要重新生成时要求真实透明，避免白边与黑边。
