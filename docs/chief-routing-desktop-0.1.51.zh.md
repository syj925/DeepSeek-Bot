# QibitAI 桌面功能更新 0.1.51

日期：2026-10-19。插件版本为 0.1.51，不改变桌面应用自身版本号。

## 行为

- 主页输入默认直接发送给总助理；搜索使用左侧独立小按钮。常用功能可填入简短提示，已有用户文本不被覆盖或暗中添加前缀。发送期间防止重复提交，失败保留原文。
- Chief 先按交付目标分流：简单问答、解释、天气可直接回答；报告、表格、图片、代码等明确产出先创建或复用任务群。单个专业员工也可任负责人，收集需求、执行及交付均留在群内。已有员工优先，能力确实缺失才创建临时员工。同一任务修改复用原群；已在群内或收到内部回执不再建群。用户明确要求亲自处理时遵从。
- 分流通过系统指令和工具参数说明落实，没有用关键词硬拦截所有自然语言，也未修改 Harness。实际模型遵循率仍需真实使用评估；模拟测试只验证指令装配与工具执行链，不能保证每种模型的决策。
- 桌面聊天增加常驻执行状态：已提交、等待模型、工具执行、流式回复、待授权、待补充信息、报错；显示实际运行计时。45 秒没有新的可见进展时提示查看执行过程，不宣称网络已断开、不制造完成百分比，不自动重发。
- 合并位置恢复：小窗使用已确认参考位置，大窗居中偏上；手动拖动后，自动整理卡片可恢复默认锚点并将其作为员工排布的避让区域。
- 合并此前融球距离、松手判定、拖动批处理、角色动画闪动修复和真实工作概览。
- 随包提供设计师补充包的 Noto Sans SC 可变字体及 OFL 许可证，通过插件已认证接口按需加载，不安装系统字体、不把字体塞入客户端 JS。主发送/提交按钮使用黑白状态，保留头像、Dock、开关及选项卡自身视觉。字体和按钮为组件级接入，保留现有布局尺寸与 Markdown/代码语义；Mac 视觉验收未执行。
