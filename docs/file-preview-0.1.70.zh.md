# 文件卡片预览修复 0.1.70

## 原因与修复

画布会话嵌入宿主聊天，回答尾部的产出文件卡片仍使用经典 sidebarRight 预览回调。画布替代经典主会话界面时，没有可供该回调操作的右侧会话界面，因此抛出 `no session surface is mounted`。

在我们自己的 CanvasConversation 根节点接管产出卡片的预览点击，将卡片的本地路径和当前会话身份传给现有 openConversationFile / openCanvasFile。通过卡片语义标记限定预览按钮，不依赖混淆后的 CSS 类名，不修改宿主实现；不接管复制路径、WPS 或其他外部应用菜单，不改正文现有文件路径处理。键盘触发与点击相同，嵌套会话只由自己的根节点处理。

## 验证

- 全部 1206 项单元测试通过；构建一致性、lint 通过（既有警告保留）。
- 新增 4 项回归，覆盖员工/群聊会话身份、键盘/鼠标点击、原生菜单不拦截、经典模式和缺失路径、嵌套会话。
- 隔离 mock 环境通过真实 present 工具生成 CSV、Markdown 文件卡片，在团队栏和拖出弹窗分别打开并断言读取内容，共四种组合通过，页面异常为零。
- 安装通过正式桌面插件管理器；保留 0.1.69 回退包，dev 不变。

## 存储评估

正式打包版固定使用 AppData/qibitai；安装到其他盘不等于数据存到其他盘。建议后续提供存储位置配置和受控迁移：复制并校验、切换路径、保留历史绝对路径兼容、支持失败回退。默认清理仅限有生命周期定义且可再生成的缓存，不自动删除会话、附件、产物或在用运行依赖。此版本没有修改用户数据位置，也未实现存储设置。

部署完成：0.1.70 发布包的 75 个文件均与安装文件 SHA-256 一致，实机确认画布和团队栏已挂载。隔离测试进程已停止，正式桌面恢复普通启动。
