# 0.1.67 信息栏恢复

日期：2026-10-22。基线为 main 的 dc1edcd（0.1.66）。修改前确认生成的 client.js 与正式桌面安装包指纹一致，host/shared 源码忽略换行后内容一致。

## 功能

- 团队栏聊天右上角以信息栏替代最大化；独立弹窗在设置与关闭之间增加相同入口。
- 集中当前任务、最近完成任务、员工近期群工作、产出文件和错误恢复，移除聊天正文里的重复卡片。实时工作状态、问题和审批保留原位置。
- 错误面板保留重试、请总助排查、查看排查答复、检查模型配置、复制错误信息。已读不等于问题已解决。
- 新信息角标按工作区和员工/群记录，在两种聊天界面间共用；任务、文件和排查状态更新后重新提示。
- 检查员工回复中明确分享的文件，保留来源会话；缺失文件明确提示。只检查分享路径，不扫描整个工作区，不索引内部员工消息或用户文本。
- 保存群聊文件来源，避免日志裁剪和员工上下文分段后丢失。旧记录支持有限历史回查。
- 修复未找到会话实体时，空 assistance.botId 误匹配无关错误的问题。
