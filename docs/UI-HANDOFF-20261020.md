## 2. 昨天未合入：对话拖出画布

这是在**画布模式下，把侧栏展开的当前单聊或群聊**拖成画布浮窗，原会话继续使用；经典视图不启用此手势。它不新建会话、不复制消息、不改变群成员、管理员、员工归属或权限。

| 文件/符号 | 合入内容 |
| --- | --- |
| `ds-bot/src/client/chat-popout.js`：`useChatPopoutDrag` | 手势、取消、文本/控件保护、轻量预览、键盘快捷键和拖后点击保护。该文件是新增文件，不能因只导出 Git 已跟踪差异而漏掉。 |
| `sidebar.js`：`TeamSidebar / useChatPopoutDrag` 接线 | 移除原 `Pop out to canvas` 按钮，接入 pointer/keyboard handlers；先 `flushSync` 卸载侧栏编辑器，再打开原实体，避免两个编辑器竞争同一个 Session。 |
| `chat-popout.js`：`stageChatPopout`、`takeChatPopout`、`CHAT_POPOUT_EVENT` | 按实体 ID 暂存并一次性消费落点尺寸；事件名 `bt:chat-popout`。 |
| `canvas-workspace.js`：`CanvasChatWindow` | 新窗口消费落点；已有窗口接收重定位事件，并回到被拖出的目标会话。 |
| `test/chat-popout.test.js`、`test/sidebar-team-chat.test.js`、`test/canvas-workspace.test.js` | 手势、身份、卸载顺序、窗口定位及回归测试。 |

交互规则：

- 鼠标从对话标题或正文非交互空白拖动，达到 **6 CSS px** 后开始拖出；普通点击或小幅移动不触发。
- 消息文字仍可选中；输入框、按钮、链接、附件、图片、滚动条和 resize 手柄不接管。自定义控件可标记 `data-no-chat-drag`。
- 在画布范围内的有效区域松手才提交。Escape、画布外释放、切换会话、滚动、失焦、窗口 resize、指针取消等路径都清理手势。
- 触屏只允许从标题拖动，正文保留滚动。对话外壳聚焦后可用 **Ctrl/Cmd + Shift + Enter**；输入框及 IME 组合输入不接管此快捷键。
- 拖出后的误点击保护最长 600ms；新的 pointerdown 和键盘点击不会被长期吞掉。
- 落点和尺寸采用浏览器 CSS 像素，通过 `fitChat` 收在画布边界内，不使用世界坐标去移动原头像。
- **浮窗位置/尺寸当前仅在内存中传递和保存，不承诺跨刷新持久化。**

### 拖出交互验收

1. 单聊、群聊分别从标题与正文空白拖出；核对同一会话 ID、原消息、成员和管理员，不能生成一条新会话。
2. 检查输入、选中文字、滚动、附件和关闭操作仍可用；从输入框拖动不能触发拖出。
3. 拖动后 Escape、画布外释放、切换会话、滚动或 resize 应取消，不能误开旧会话。
4. 同一会话已有画布浮窗时再次拖出，应复用并重定位原窗口；不能出现同一个 Session 的重复编辑器。
5. 真实宿主复核未发送草稿、已选附件、正在回复、工具/审批状态、IME，以及刷新重开后的行为。
6. Windows Chrome/Edge 的 100%/125% 显示缩放、小窗口与触屏标题拖动分别复核。

**与其他拖拽分开验收**：员工头像拖入群聊是邀请成员；两员工头像重叠是建群/协作；本节拖出的是当前对话的展示窗口。三者不能只测其中一个就视为都通过。
