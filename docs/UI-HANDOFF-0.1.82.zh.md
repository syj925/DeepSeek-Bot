## 接手方式

先阅读根目录 `AGENTS.md`、`UI-HANDOFF.md`、本文件及 `ds-bot/package.json`。从交付提交建立独立 UI 分支。设计师负责视觉与交互设计，功能侧保留确认过的设计；接手 AI 不自行改换整体风格。直接修改真实组件，保留 actions、订阅、身份标识、权限和状态管理。需要新数据时列出接口需求，不用演示数据覆盖真实业务。

修改 `src/client/` 后重新生成 `client.js`。纯 UI 工作不更改 Host 的任务、上下文、记忆或权限规则，也不修改 Harness、安装目录及用户数据。历史交接包仅供参考，不可整体覆盖本版。

## 信息栏保持三个分类

| 分类 | 内容 | 必须保留的交互 |
| --- | --- | --- |
| 任务 | 历史任务、相关协作 | 展开任务可查看状态、检查点、验收和成果版本；相关协作是对应群聊跳转入口。 |
| 成果 | 产出文件、岗位经验 | 文件保留图标、名称、来源和打开入口；经验属于当前员工，可编辑并查看已记录的来源。群聊按实际成员展示经验。 |
| 待处理 | 任务问题、授权、工具与环境问题、错误恢复 | 显示真实阻塞和恢复操作。收起后保留标题与数量，不能将隐藏内容视为处理成功。 |

分区标题行可收起／展开，同一会话的团队栏和弹窗共用本机偏好。隐藏内容时保留组件，避免丢失正在编辑的经验草稿。偏好按工作区与稳定员工／群 ID 区分，不写入模型上下文，不代表跨设备同步。

不可用文件默认折叠，不占可用文件的前四个位置和数量。展开可重新检查或逐条移除列表记录。移除不删除磁盘文件、任务历史或归档交付，提供最近一次移除的撤销入口。标记绑定记录版本；文件恢复可用或重新交付后可再次展示。保留文件来源会话与任务交付 ID，不按文件名猜路径。

岗位经验来源行使用 `来源：任务名 · 员工名`。展开只显示已保存的原任务摘要与有效会话入口；不能根据相似标题猜测来源。来源摘要不是新推理，也不自动成为已确认业务规则。编辑与更多按钮保持对齐；移除经验与移除文件列表记录是两种不同操作。

## 任务、上下文与恢复边界

- 普通问答仍使用员工会话。多步骤交付可登记独立任务，仅关联实际参与者与必要对话。
- `complete_task` 保存交付并等待用户验收，模型不能替用户验收。验收、返工、继续和补偿同步都使用正确任务 ID 与修订号。
- 明确的新任务指令建立新执行上下文，明确续做保持当前任务。已登记任务中的模糊输入在输入框旁询问，消息与附件先保留，选择后执行。不要将入口移入历史任务深层菜单。
- 私聊任务验收后重置执行上下文，保留历史、交付版本与岗位经验。经验按查询读取，不把全部旧任务摘要注入新上下文。查看和编辑记忆仍受服务端权限及修订校验约束。
- “标记已处理”收起提醒并保留诊断，不重试任务。同一会话后续有效成功回复可清理旧模型错误；空回复、纯转交和其他员工诊断不等于恢复。
- 继续任务、重试、授权与查看必须区分，不能将 UI 操作接到自动重复执行外部任务的逻辑。

## 主要代码入口

以下路径相对于 `ds-bot/`：

| 文件 | 责任 |
| --- | --- |
| `src/client/conversation-task-panel.js` | 信息栏入口、分类、文件与分区组织 |
| `src/client/panel-section.js` | 标题、收起／展开及可访问性 |
| `src/client/task-panel-preferences.js` | 本机偏好、移除记录版本和窗口同步 |
| `src/client/job-experience.js` | 经验编辑、来源与草稿 |
| `src/client/task-input.js` | 输入框旁的新任务选择 |
| `src/client/work-tasks.js` | 任务详情、验收、返工与成果版本 |
| `src/client/model-recovery.js`、`task-permissions.js`、`tool-issues.js` | 恢复、授权与环境问题 |
| `src/host/work-tasks.js`、`work-task-integration.js` | 任务记录、执行关联、成果快照与验收 |
| `src/host/task-input.js`、`task-context.js`、`parts.js` | 输入保留、上下文切换和分段 |
| `src/host/memory.js`、`recovery.js` | 经验存取及错误生命周期 |

API 约束见 `independent-tasks-mvp.zh.md` 和 `task-context-isolation.zh.md`。使用现有 actions，不另建任务状态或文件索引。

## 验收与回传

运行 `npm test`、`node scripts/build-client.mjs --check`、`npm run lint`；Host 变更另需使用独立 `.dsh-test-*` 与 mock 模型检查。不能使用正式用户会话测试。

视觉验收覆盖窄窗／正常宽度、私聊／群聊、团队栏／独立浮窗、空列表／正常／不可用文件、移除与撤销、收起后重开、编辑中收起、多窗口同步与待处理数量。保留键盘焦点、按钮标识和滚动行为。

回传基准提交、文件差异、截图或录屏、验证结果和未解决问题。不附带个人会话、密钥、浏览器个人配置、依赖目录或测试运行数据。
