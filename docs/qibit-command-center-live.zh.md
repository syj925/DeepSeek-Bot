# QiBit 中央组件真实工作概览

2026-10-19，本次改动基于 0.1.47。保留人物、玻璃卡片与四功能布局。

- 单击人物展开/收起。超过 6px 的拖动仅移动组件，松手后的 click 不触发收起。键盘箭头移动，Home 恢复自动定位。
- 删除底部示例/收起/对话小字和独立加减按钮。
- 未手动移动时水平居中，展开整体位于可用垂直余量的 35% 位置；折叠操作不保存绝对坐标。已保存的手动位置继续保留；窗口缩小时仅约束可见位置，放大后恢复首选位置。
- 计划读取任务群目标与状态、私聊完成记录、当前私聊执行状态、审批、模型失败和真实自动化日程。普通消息不计作完成任务。
- 数据/会议/客户模块依据任务标题与成果摘要的关键词筛选已有记录，可交叉归类。不是独立的 CRM 或会议数据库，不推测缺失的业务指标、决策、负责人、优先级或截止时间。
- 卡片点击打开来源对话或日程配置；进度是“已完成 / 已记录任务”，不承诺覆盖未结构化记录的所有工作。
- 选择功能后输入实际需求，通过既有 send 接口发送给总助理；未选功能时保留原搜索行为。提交失败保留输入，防重复提交。无记录显示空态，未启用日程显示未启用。

验证：897 项测试通过；lint 通过（既有警告）；构建一致性和 diff 检查通过。隔离浏览器验证 960×640、1440×900、1920×1080 居中、人物收放、拖动、调整窗口与发送失败保留输入，无页面异常；不调用付费模型。

经用户要求，已打包为插件 0.1.48，通过桌面插件管理器安装并重启。实际安装版本与 client.js 哈希均已核对；人物收放、底部小字移除、真实卡片和居中位置已在桌面验证。此前安装时由助手添加的偏移已通过人物的 Home 操作恢复自动定位。未发布 GitHub。
