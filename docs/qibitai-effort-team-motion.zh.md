# 思考强度工具与团队栏动效修复（0.1.40）

## 原因与改动

设置页与宿主已有 effort 设置能力，但 `update_bot` 工具没有暴露该参数，`list_models` 也没有给员工提供支持的档位。现补齐查询与修改入口，保留原有管理权限：员工可修改自己，总助和主管须遵守现有员工管理边界。

- `update_bot.effort` 修改后续轮次的员工默认档位；空字符串恢复模型默认。
- `message_bot.effort` 为一次排队任务指定档位，不更改员工默认值。不指定时仅继承目标模型支持的员工档位。
- 不支持的档位明确拒绝，不自动提升权限；模型和档位组合先校验，避免失败后只改了一半。
- 已开始的请求保持原参数，从下一轮生效；不取消当前工作。

团队栏展开时，原聊天区跟随外框每帧改变宽度，长消息重复换行，叠加布局观察、列表动画和毛玻璃绘制。现在外框保留过渡，聊天内容按最终宽度排版后揭开；关闭时也保持内容宽度。统一几何动画时长、减少无变化尺寸通知导致的重绘、避免列表动画叠加，移除不必要的全属性过渡和持续动画占用。保持现有视觉样式和可拖拽缩放功能。

## 验证

- 模拟模型执行 `update_bot` 修改 Low，下一次实际 HTTP 请求包含 `output_config.effort: low`。
- 权限、无效档位、默认还原、一次性任务隔离和参数应用有自动化测试。
- 同一测试环境，展开时聊天区采样到的不同宽度：原布局 8 个，优化后 1 个。说明消除了反复水平排版；不代表所有设备的 FPS 提升比例。
- Chromium 打开和关闭交互验证通过，无页面异常。
