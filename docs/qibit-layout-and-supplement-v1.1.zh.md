## 补充包 v1.1

这是针对 0.1.46 / fc02507 的规范、字体和 CSS 示例，不是新功能源码。18 个清单文件 SHA256 均与包内 manifest 匹配；未运行附带诊断脚本。

1. 字体：官方 Noto Sans SC 可变 TTF（17,772,300 字节），附 OFL 和来源。要求跨平台使用同一文件，普通 400、按钮 500、标题 600，覆盖画布、菜单、Portal、真实聊天，同时保留用户聊天字号。
2. 按钮：主按钮 #171717 白字；次按钮白底黑字黑边。明确悬停、按下、禁用、加载、焦点、深色主题；头像、Dock、Tab、开关不全局改黑。
3. 验收：24 项，包含输入法、显示缩放、滚轮单位、拖拽成员正确性和会话切换。包内声明尚未完成 Windows 实机或生产字体接入。

## 与当前版本的差异

- 当前仍有多处系统字体链，没有统一应用字体，规范确有价值。需经宿主公开资源接口加载，不能直接用不存在的 /fonts URL，也不应把 17.8MB TTF 原样塞进 client.js。
- 当前绿色操作按钮与新规范有差异；需逐组件接入 variant，不能用全局 button 覆盖。
- 规范保留旧 Dock 底座 scaleX 1.09；0.1.49 为减少毛玻璃重采样已取消底座缩放并保留图标弹簧。应专门比较视觉与性能，不能用旧示例覆盖当前修复。
- 规范提及 y−40/y−56 拖入偏差，0.1.50 已按真实头像中心统一；不要还原成旧实现。
- 不承诺 Mac/Windows 抗锯齿逐像素一致；当前未有 Mac 同数据对照，24 项不能标成全部通过。
