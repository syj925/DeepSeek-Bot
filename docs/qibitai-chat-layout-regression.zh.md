# 0.1.42：桌面聊天区空白与通知点击

## 根因

0.1.41 为嵌入聊天区设置了 `height:0!important`。隔离测试使用的宿主中，聊天内容直接属于纵向 flex 容器；桌面实际宿主多了一层 `[data-conversation-content-frame]`，其布局轴不同，导致内容高度为 0，聊天与输入框全部被裁切。真实桌面 DOM 测得外层 626px，内容层 0px；聊天数据并未删除。

## 修复

- 明确内容框为纵向弹性布局，内容高度改为 auto，保留 min-height:0 和滚动边界；兼容有/无内容框两种结构。
- 通知正文、头像、卡片空白均可跳转原会话，取消“打开对话”按钮。
- 保留独立关闭和文件打开行为，避免事件冒泡重复跳转；支持 Tab、Enter、空格键操作。
