# 0.1.50 交互修复

- 总助理策略建议：简单问答直接处理；明确交付任务优先匹配现有员工；缺少必要能力才创建临时员工；多人依赖时建任务群。此版本未强制改动后端调度策略。修复首页发送时无条件追加所选概览的提示词，避免“写报告”被变成“整理工作计划”。
- 桌面空白左键清除浏览器文字选区；桌面装饰、团队列表不再产生原生拖选蓝底，输入框和聊天正文仍可选择文字。
- 进度卡取消溢出的滚动条，进度线改为圆角细线；其余卡片保留细滚动条以访问长内容。
- 人物静态图常驻，动画结束淡出后再释放图层，避免两层同时透明产生闪空。
- 旧版未记录窗口尺寸的绝对坐标迁移到自动居中；新手动位置保存参考尺寸，缩放窗口按比例映射。旧版手动位置也会一次性重置，用户可重新拖动。
- 桌面、Dock、联系人与原生拖入按头像位置统一判断；预览 ≤120px，提交 <58px，不扩大提交距离。头像中心校正为距卡片顶部 34px。
- 重复合并相同两人时打开已有普通群；任务群不复用。群名冲突时追加序号，避免后端拒绝同名建群。

验证：905 项测试通过；lint 通过（保留既有警告），bundle 一致性通过。隔离 mock 实测 1960×1200、1280×780、960×640 自动居中、空白清除文字选区、动画结束静态图持续可见、桌面建群服务请求。所有模型测试使用 mock。
