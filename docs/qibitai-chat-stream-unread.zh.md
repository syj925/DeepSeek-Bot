# 弹窗流式显示、团队栏展开与未读状态（2026-10-19）

插件版本：0.1.38。

## 问题与修复

- 折叠团队栏点击头像后，聊天已打开但 folded 仍为 true，导致宽度、底部操作栏和聊天区不一致。选择联系人时显式展开，保持原有窗口位置约束。
- 完成消息的蓝点来自 completions，原 clearUnread 只清手动未读；团队聊天又不在画布阅读判断中。现在清除当前会话分段的完成标记，并由实际挂载、取得编辑器所有权的聊天窗口登记阅读。页面隐藏或切换其他面板时仍保留未读。关闭后不会恢复旧蓝点，之后的新回复仍可产生未读。
- 弹窗正文增加实时标记及过程容器可见性保护，避免画布通用 hidden 样式遮住实时正文。使用原生流式会话数据，不添加假打字动画，不修改模型参数。

## 验证与边界

- npm test：767 项通过；构建一致性检查通过；lint 无错误，保留既有警告。
- 隔离 mock 环境，使用 compact 显示模式及桌面同款主题；模拟先思考再逐块返回正文，弹窗出现多个中间长度，消息完成前已经显示。
- 浏览器操作：折叠栏点击头像→完整双栏聊天；后台完成→蓝点→打开聊天消除→关闭仍已读。页面无 JS 错误。
- 未使用真实用户会话发送测试、未调用付费模型。现有慢速模拟在修复前也能够流式显示，因此用户遇到的整段出现尚未完全复现，不能将其确定归因为单一 UI 问题。若实际模型或网关只在结束时返回正文，前端无法提前展示尚未收到的文本。
