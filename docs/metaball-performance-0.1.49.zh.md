# 0.1.49 融球与交互优化

日期：2026-10-19。

## 已实现

- 按交接规格保留半径 28/32、模糊 8、透明度矩阵 24/-10、岗位浅色渐变、白色细描边、绿色提示胶囊。
- 两头像距离 ≤120px 显示连桥；58–120px 提示继续靠近，小于 58px 提示松开建群。松手重新按实际坐标判定，不复用旧目标。
- 目标脉冲仅作用于头像，避免姓名与整个卡片缩放；非图片头像使用原头像组件，避免被底色盖住。
- 鼠标移动合并到每个动画帧；员工拖动使用临时 transform，只在松手提交布局。边界与桌面恢复规则一致，选择整体限位；松手提交期间禁用位置过渡，避免从旧位置再次滑入。
- 群卡命中矩形短时缓存，松手重新测量；取消拖动恢复位置。已有群加入、多人选择仍走原流程。
- Dock 已展开预览跨头像时直接更新内容；缩放变量局限于图标，降低后代样式重算。保留图标放大，停止底座毛玻璃随悬停缩放，降低预览模糊强度。
- 画布闲置人物暂停装饰循环，悬停可恢复；拖动期间暂停画布人物装饰动画。任务工作状态保持显示。

## 验证

- 900 项单元测试通过；lint 通过（既有警告保留），生成 bundle 一致性通过。
- 新增距离 121/120/80/58/57.99/0、快速松手、离开旧目标、取消、不可变临时布局回归。
- 隔离 mock 浏览器实测 120px 连桥、57px 可建群提示、真实 transform 跟随、取消恢复、头像材质；未调用真实模型，也未拿用户桌面数据做测试。
- 包目录：`D:\安装包\0.1.49`；保留 `0.1.48` 回退包。

## 性能证据与限制

同一 Dock 扫动脚本、6 项、240 次鼠标移动：先前诊断样式计算累计 2.827 秒；本次样本约 2.014 秒，下降约 29%。单样本受机器负载影响，不能视为固定加速比例。

纠正先前拖拽基线：原脚本起点被团队栏遮挡，1699 次矩形读取不能作为员工拖拽的有效基线。修正测试布局后，本次真实员工拖动 240 次移动，矩形读取 109 次，脚本 0.466 秒、样式计算 0.378 秒。无有效旧版同布局基线，因此不报告拖拽加速百分比。

Chrome headless 的帧时序不能换算为实际 Electron FPS。此次没有证明所有背景与机器上都无卡顿；团队栏等画布外装饰动画仍存在。可视分组外框拖动仍采用每帧状态更新，尚未改成独立 transform 层。
