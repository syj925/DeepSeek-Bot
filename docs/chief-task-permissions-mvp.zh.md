# Chief 拓客任务授权 MVP · 0.1.71

本版解决员工在拓客执行中等待批准、用户找不到继续入口的问题。它是任务授权的第一步，不代表已经完成每日拓客、名单质量评审和销售反馈学习的完整工作流。

## 使用方式

1. 在「设置 → 偏好设置 → 任务授权」开启「允许总助理代管拓客任务授权」。默认关闭，模型不能自行开启或扩大范围。
2. 开启后页面会显示资料目录和产出目录。把本次允许员工阅读的公司定位、筛选要求等资料放入资料目录。
3. 将拓客任务交给 Chief。Chief 可以通过 `authorize_prospecting_task` 对指定员工的私聊或指定群聊执行上下文授权，再在同一个对话下发任务。
4. 打开聊天右上角「信息栏」，可以查看待批准操作、当前授权和最近授权记录；可以撤销当前授权。
5. 群聊已经卡在批准处时，可点击「交给总助理审核本次任务」。软件按已开启的预设检查真实工具和参数，符合范围时继续原来的操作，不重新发起一遍任务。该按钮执行规则检查，不是另发一次模型审查请求。

## 固定授权范围

| 操作 | 本版可自动批准的范围 |
| --- | --- |
| 公开搜索 | 标准 `web_search`，每次 1–5 个查询，每条最多 1,000 字符 |
| 读取资料 | 结构化 `read`，仅团队工作目录下 `prospecting-inputs` 内已有普通文件 |
| 生成名单、报告 | 结构化 `write`，仅 `outputs/prospecting` 内新建 `.csv`、`.md`、`.txt`、`.json`；最多 2,000,000 字符，父目录必须存在 |

不会自动批准覆盖已有文件、编辑、删除、Shell/PowerShell、代码执行、网页抓取和浏览器控制、外发消息、连接器、付费购买。路径越界、符号链接或目录联接也不能获得自动批准。需要这些能力时保留宿主的批准/拒绝机制，不修改沙箱，不通过外部进程绕过限制。

CSV 可以在表格软件中打开，但本版没有新增 XLSX 排版引擎，也不能保证搜索结果的准确性。

## 授权生命周期

- 仅实际总助理身份可以调用授权工具；普通主管、员工不能冒充 Chief。
- 授权绑定员工和具体执行 Session，群聊与私聊之间、不同群之间不能串用。
- 对当前执行轮次有效；员工尚未执行时，对下一轮有效。最长 30 分钟，轮次结束即失效。后续轮次需要重新授权。
- 撤销、关闭开关、员工退休或被移出群、群任务完成等都会使授权失效。
- 用户预设和最近 100 条审计记录保存到 Bot 状态；临时授权只在内存中，软件重启后不恢复。信息栏显示所属对话最近 5 条记录。
- 自动批准前检查真实调用 ID、工具名和结构化参数，并记录审计；记录保存失败时不自动批准。异步检查期间撤销也不能放行。
- 已经放行并执行中的操作不会因撤销而回滚；撤销作用于后续批准。

## 私聊与群聊的差别

Chief 提前授权后，两种对话中新出现的合规批准请求均可自动处理。

群聊隐藏的员工 Session 由 Bot 管理批准，所以支持信息栏内允许一次、拒绝，以及 Chief 规则审核后继续原操作。已经交给宿主原生界面等待处理的私聊批准仍由原生界面回答；信息栏提供打开该员工对话的入口，不承诺点击 Chief 会接管此前的原生请求。

硬性拒绝、工具未安装、服务商密钥或余额问题、请求失败不属于授权等待，不会通过这套机制自动修复或无限重试。

## 实现入口

- `ds-bot/src/host/chief-permissions.js`：用户预设、临时授权、工具参数检查和审计。
- `ds-bot/src/host/approvals.js`：接入公开 `approval/request` 事件，恢复原来的待批准请求。
- `ds-bot/src/host/channel.js`：用户设置、审核、撤销接口及实时状态。
- `ds-bot/src/client/task-permissions.js`：信息栏授权区。
- `ds-bot/src/client/settings.js`：用户开关和目录说明。
- `ds-bot/test/chief-permissions.test.js`：身份、会话隔离、期限、撤销、持久化失败、文件边界和原请求恢复测试。

## 验证与交付边界

全套单元测试、客户端构建一致性检查、lint，以及 40 步隔离 mock host smoke 均通过。另在独立测试插件中用公开 `tools/pre-execute` API 强制写入等待批准，验证了：

1. Chief 经真实模型工具接口授权，私聊员工通过宿主批准链写出 CSV，并独立读回核对。
2. 群聊员工先等待批准，Chief 授权后原操作继续执行，CSV 可读，临时授权在结束后消失。
3. 浏览器设置开关可用；信息栏审核按钮可恢复群聊写入，浏览器没有页面异常。

以上使用模拟模型和隔离数据，不是实际客户搜索质量验收。测试批准插件仅在测试环境加载，不包含在安装包中。正式桌面是否更新以部署记录为准，不能用源码版本或测试截图代替安装验证。
