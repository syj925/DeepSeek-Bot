# 协作记录与桌面交互更新（0.1.61）

- 消息内的协作头像与提示行打开协作记录，顶部身份头像不改变用途。
- 协作记录浮层优先覆盖来源聊天窗口；无来源窗口时居中显示。右上关闭、Esc、焦点返回，原聊天不卸载。
- 记录按时间排列，每 2 秒更新（页面隐藏时 8 秒）；上翻时保留位置，通过“查看新消息”回到底部。请求失败保留已有内容并提示重试。
- 工作状态仍直接显示在原聊天中；记录页显示真实员工工作状态，不把空闲当作任务完成。
- 桌面组件可右键删除，在显示设置恢复；会话卡片从桌面移除不删除员工或群聊数据。
- 团队列表按手动置顶、未读、消息时间排序；内部交流不把私聊错误刷新到前列。
- 空白画布菜单：新建、自动整理卡片、重置画布视角、日程、个性化壁纸、显示设置。

验证：966 项单元测试通过；构建一致性、lint、diff 检查通过（lint 保留已有警告）。隔离组件浏览器测试覆盖更新、滚动保持、失败保留数据、小窗边界、关闭恢复草稿与焦点。正式桌面只查看已有交流记录、检查菜单，未发送测试消息。通过应用公开插件安装页面安装 0.1.61，安装后 client.js SHA256 与源码构建一致。
